# Exploding-Coaster
This is an exploding coaster that uses a rubber band and is made out of 3D printing. I has a pause in the layer to insert the rubber band amd has print in place joints.

## Assembly:
Insert a pause in the print at layer 33 if using standard 0.4mm profile, or here:
